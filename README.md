# Tests skola — demonstrācijas versija

Publiska testa kopija no [rvaldofkuul.lv](https://rvaldofkuul.lv) ar **izdomātiem datiem**.
Paredzēta Latvijas skolām, lai apskatītu grafiku skatītāju (stundas, konsultācijas, pulciņi, šodienas skats).

**Šī nav īsta skola.** Vārdi, adreses un grafiki ir fikcija.

## Adrese

- Vietne: `https://skola-demo.vercel.app`
- Parole: `Tests123?`

Vercel neļauj pasvītru (`_`) projektā, tāpēc adrese ir `skola-demo`, nevis `skola_demo`.

## Ko var izmēģināt

1. Atvērt vietni un ievadīt paroli.
2. Parka iela (P) — 1.a, 2.a, 3.a, 5.a.
3. Ezera iela (E) — 6.a, 7.a, 8.a.
4. Šodien / stundu saraksts / konsultācijas / pulciņi.
5. Meklēšana pēc skolotāja, telpas vai pulciņa.

## Īsie demo dati

- 7 klases (oriģinālā ir pilns 1.–9. klašu komplekts)
- 7 pulciņi
- 7 konsultācijas
- Izdomāti skolotāji (Anna Liepiņa, Jānis Ozols, u.c.)

## Lokāli

```bash
npm install
npm run dev
```

Atveriet [http://localhost:3000](http://localhost:3000). Parole: `Tests123?`
